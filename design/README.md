# Suki design files

- `brand/BRAND.md` — brand rules: the idea ("Suki ghostwrites. You sign."), colour roles, type, voice.
- `brand/tokens.css` — the shared design tokens (colours, type, radii). Change a token here first, then in the app.
- `brand/icon.webp` — the Suki app icon.
- `suki-prototype.html` — a clickable prototype of the redesign (landing, sign-up, campaigns, review, Brand Brain, Accounts, Trend references). Open it in a browser. All content in it is sample data, and nothing typed into it is saved.

The live landing page is `src/app/welcome/`. It is the reference for how the tokens are used in the app.
